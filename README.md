# SideSwipePSP
A Rocket League SideSwipe inspired game for the PSP


This is the first release of Rocket League Portable, a Rocket League SideSwipe style game for the PSP. The game physics are a little different, but you will quickly get used to it.

It is AI assisted as there was not much information on the internet about coding a PSP game in Lua. However, after learning some of the basics, I did code a lot of it myself. 

This game is still a work in progress. I know there are a couple of bugs, but I am very open to feedback, so please let me know what you think. 
I hope you enjoy!

P.S. The garage does not currently work, 
PPSSPP is currently unsupported.


## Controls:
Left/Right: D-pad,
Tilt Up/Down: L/R,
Jump/Flip: X,
Boost: O

## Installation:
Copy the SideSwipePSP folder and extract it into PSP/GAME/ on your PSP
